## 已确认口径

| 事项 | 结论 |
| --- | --- |
| 选样单位 | 每条记录只归入一个标签：取 OP-05 `labels[]` 中 confidence 最高者，平票按路径字符串排序；无标签记录不入选 |
| 配额 | 来自 OP-15 `feedCount`；实际选样 ≤ min(配额, 可用记录数)；缺口如实记录，不重复选样 |
| 抽样可复现 | 每标签内按 `sha256(seed|record_id)` 升序取前 N；不使用 `random` |
| 成品格式 | Parquet + zstd，按 `modal/source/dt` 分区；分片默认 100000 行；row group 约 128 MB（配置） |
| 续跑 | `checkpoint.json` 记录已完成标签与已选 record_id；同一 runId 重跑从未完成标签继续，不重复不丢样 |
| 评测真值 | H-05 未提供：准确率/F1/混淆矩阵标 `null` + `TRUTH_REQUIRED`；有真值时按精确/前缀匹配双口径计算 |
| 代理指标 | 无真值时只输出「与 OP-05 标签一致率」「路径合法率」「字段完整率」等代理指标，明确标 `proxy=true`，不冒充准确率 |
| 合规/版权 | 词表/版权库未提供：`unavailable` + `COMPLIANCE_RESOURCES_REQUIRED`；提供后按词表命中与哈希比对 |
| 综合质量分 | 只用可用分项加权；权重来自配置并记录来源；不可用分项剔除后权重重归一，全部不可用标 `null` |
| 九维报告 | 维度/阈值/权重为联调初值（H-03）；每个维度必须引用真实算子 `metrics.json`，缺数据标 `no_data` |
| 渲染 | 算子只产数据包；HTML 渲染可选，失败不影响数据包 |
