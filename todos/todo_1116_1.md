### 关键设计决定

1. **包名与目录名一致**：`importlib.import_module("dm-multimodal-analysis.core")` 已实测可用；包内 `from .utils import ...` 正常。禁止写 `import dm-multimodal-analysis`（连字符不是合法标识符），此规则写入契约文档。
2. **healthz 的 `ready` 不含权重**：`ready = core 可导入 + 输入/输出目录可写 + 路由注册成功`；权重就绪单独用 `weightsOk` 表达。这样 S0 的 22 个 healthz 可通过，模型型算子又不会假装权重已就位。
3. **骨架 predict 不伪造结果**：`core.run` 抛 `NotImplementedError("OPERATOR_NOT_IMPLEMENTED")`，HTTP 层转 `code=1` + `reasonCode`；契约测试把它作为「业务失败」用例，而不是虚假成功。
4. **共享基线放 `baseline/`**：树快照必须进镜像，不能放 `docs/`；`baseline/` 加入 `Dockerfile`、`.dockerignore`、打包 allowlist 三方一致。
5. **allowlist 单一来源**：`scripts/bundle_allowlist.txt` 同时被 `.dockerignore` 生成与打包脚本消费，避免两份清单漂移。
6. **S0 证据目录**：`docs/算子开发/evidence/S0-<工作包>/`，与算子证据 `operator/<dir>/output/evidence/<runId>/` 分开。

### 版本号口径（不是发布 ID）

- `map.json` 的 `version`、`core.OPERATOR_VERSION`、镜像/压缩包版本是**代码版本**，用于结果复算与幂等，不产生对外发布 ID。
- 任务书要求（3.4/3.5/3.8）：结果信封必须带 `operatorVersion`；`runId = sha256(输入指纹 + operatorVersion + paramsHash + seed)[:16]`；镜像 tag、压缩包文件名、`map.json` 版本三者一致。
- S0 统一用 `0.1.0`（骨架未验收）；S7 正式交付时再定 `1.0.0`。
- `registry.json` 的 `publishId` 留 `null`，并注明「按人工确认不生成发布 ID」。
