## 实施方案

每个算子独立目录，统一结构（沿用 S2）：`configs/*.json`、`utils/common.py`（复制并注明来源）、算子专属 utils、`core.py`、`tests/`、`README.md`、`dataset/{sample,DATA_SCHEMA.md}`、`output/evidence/<runId>/`。

```text
dm-corpus-profiling/     configs/profile.json    utils/{common,io,scale,source,ahp,domain}.py
dm-language-profiling/   configs/language.json   utils/{common,io,lang,timeparse,region}.py
dm-text-profiling/       configs/text.json       utils/{common,io,segment,lexical,syntax,genre,taskfit}.py
dm-quality-analysis/     configs/quality.json    utils/{common,io,completeness,conflict,gini,difficulty,polarity}.py
dm-stratified-sampling/  configs/sampling.json   utils/{common,io,strata,neyman,sampler}.py
dm-speech-analysis/      configs/speech.json     utils/{common,io,asr,acoustic,wer}.py
dm-visual-analysis/      configs/visual.json     utils/{common,io,image,video}.py
dm-knowledge-analysis/   configs/knowledge.json  utils/{common,io,terms,timewin,style}.py
```

关键决定：

1. 输出统一包含 `result.jsonl`（逐记录）、`metrics.json`、`manifest.json`、`summary.json`、`input_manifest.json`、`failures.jsonl`；汇总指标放 `metrics.json`，可下钻清单单独 jsonl。
2. 每项指标在 `configs` 或 README 标注公式、样本量、阈值来源；无可计算数据时写 `null` + reasonCode。
3. 抽样与时间窗口等随机/外部相关项固定 seed 与窗口参数并写入 manifest。
4. 不引入新的大型依赖：OP-11 用已有 funasr/librosa，OP-12 用 opencv/pillow，其余纯 Python + numpy/scipy。
5. P1 算子复用 P0 的同一批 OP-02 记录与同一 `treeVersion`。
