## 实施方案

```text
operator/dm-multimodal-analysis/
├── __init__.py
├── core.py                     # 编排：扫描 → 判模态 → 分模态解析 → 记录/清单/指标
├── configs/
│   ├── formats.json            # 后缀/MIME/魔数映射、模态白名单
│   └── parse.json              # 切页/抽帧/解码/大小限制等参数（标来源）
└── utils/
    ├── detect.py               # 扩展名 + 魔数 + 容器探测，输出 confidence/evidence
    ├── textparse.py            # 编码探测、乱码率、jsonl/json/xml/txt、PDF 文本与扫描页
    ├── media.py                # 图像/音频/视频属性、ffmpeg 探测、抽帧、音轨拆流、VAD
    ├── hashes.py               # md5/sha256/simhash/phash
    ├── source.py               # 六类来源规则打分（消费 baseline/source-map.json）
    └── records.py              # 标准记录组装、分区、指纹、runId

operator/dm-corpus-normalization/
├── core.py                     # 编排：读记录 → 校验 → 标准化 → 去重 → 索引 → manifest
├── configs/normalize.json      # 标准格式/分区/去重阈值（标来源）
└── utils/
    ├── readers.py              # 读 OP-01 result.jsonl / manifest / 源文件定位
    ├── schema.py               # 复用 docs Schema 的轻量校验（运行期不依赖 docs）
    ├── writer.py               # Parquet(zstd)/WebP/WAV/MP4 写出与字节统计
    ├── dedup.py                # 精确哈希 + SimHash 分带 + phash 近重复
    └── index.py                # 元数据宽表、缺失字段、跨模态关联、分区统计
```

关键设计决定：

1. **不跨算子 import**：OP-02 只读 OP-01 的 `result.jsonl`/`manifest.json` 产物；公共工具按任务书 2.1 允许复制小函数，并在文件头注明来源与版本。
2. **混合文件拆流**：HTTP 层负责 zip 解压；`core` 仍对 `.zip` 做防御性处理（仅核心直接调用/CLI 场景），复用同一套 basename 白名单与大小限制。视频含音轨时拆出 16k mono WAV，键为 `sourceRecordId`，写入 `metadata.extra.derivedFrom`。
3. **记录粒度**：文本 jsonl 逐行一条；txt/json/xml/PDF 每文件一条（PDF 页级信息放 `metadata.extra.pages`）；图像/音频/视频每文件一条（视频关键帧/音轨作为 `metadata.extra.streams`）。
4. **record_id 稳定**：`r_<sha256(相对路径 + \0 + 内容sha256)[:24]>`；文本逐行记录用 `r_<sha256(内容)[:24]>`，同内容同 ID，便于去重。
5. **dt 口径**：默认 `file_time`（文件修改时间）；可用 `params.dt_source=ingest_time|content_time|file_time` 覆盖。未确认项在 manifest `notes` 标注 `provisional`。
6. **幂等**：同一输入/版本/参数/seed 落到同一 `output_dir`；重跑整体覆盖产物，不产生第二份；输出按相对路径排序写，保证哈希可复现。
7. **不伪造指标**：解析失败逐条进 `failures.jsonl` 并写 `reasonCode`；空文本率、乱码率、解码失败数均为真实统计；无 OCR 时输出 `ocrStatus=unavailable`。
8. **OP-02 标准产物可读**：文本 Parquet 用 pyarrow+zstd，按 `modal/source/dt` 分区；图像 WebP；音频 16k mono WAV；视频 H.264 MP4（编码器不可用时流复制并在 metrics 标注）。
