## 实施方案

```text
operator/dm-text-clustering/
├── core.py                     # 读 OP-02 文本 → 分块向量 → K 搜索 → 聚类 → 主题词
├── configs/cluster.json        # 模型路径、维度、切窗、K 范围、seed、轮廓采样
└── utils/
    ├── embedder.py             # bge 向量（transformers + mean pooling + L2）
    ├── chunking.py             # 512 token 切窗/合并
    ├── cluster.py              # KMeans/MiniBatch、轮廓系数、c-TF-IDF
    └── io.py                   # 记录读取、npy/jsonl 写出

operator/dm-multimodal-labeling/
├── core.py                     # 读 OP-02 记录 → 分模态取证据 → 向量 → 标签 topK
├── configs/label.json          # 模型路径、树版本、阈值/topK/温度、OCR/ASR 参数
└── utils/
    ├── tree.py                 # 树加载、叶子路径、路径合法性
    ├── embedder.py             # bge 向量（复制 OP-03 小函数并注明来源）
    ├── ocr.py                  # RapidOCR 图像/关键帧
    ├── asr.py                  # FunASR paraformer
    ├── vision.py               # 视频抽帧/音轨复用 ffmpeg
    └── labeler.py              # 相似度→softmax→topK→低置信池
```

关键决定：

1. OP-03/OP-05 只读 OP-02 的 `records.jsonl` 与标准媒体路径（`standardPath`），不 import 其它算子代码。
2. 标签候选 = 内容树叶子节点（279 个），向量缓存到输出目录，重跑可复用；`treeVersion` 写入结果。
3. 低置信规则：`confidence < 0.25` 或 `top1-top2 < 0.05` → 未归类池，写 `UNCLASSIFIED_LOW_CONFIDENCE`/`UNCLASSIFIED_SMALL_MARGIN`。
4. 无证据：图像 OCR 为空、音频 ASR 为空、视频两路皆空 → `UNCLASSIFIED_NO_TEXT_EVIDENCE` / `UNCLASSIFIED_NO_SPEECH`。
5. 向量与标签结果可复算：seed、模型版本、树版本、参数哈希写入 manifest/metrics。
6. 模型权重 1.3 GB 进镜像（离线可运行）；`SHA256SUMS` 构建期校验；运行期不联网。
