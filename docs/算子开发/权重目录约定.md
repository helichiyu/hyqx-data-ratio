# 权重目录约定（S0 冻结）

单一权重根，避免同一模型在多个算子目录重复打包：

```text
operator/weights/
├── README.md              # 本文件（仅仓库，不进镜像）
├── SHA256SUMS              # 构建期校验清单（进镜像）
├── shared/                 # 跨算子共享权重（进镜像）
│   ├── bge-m3/
│   ├── clip-vit-base/
│   └── whisper-small/
└── <operatorId>/           # 仅该算子使用的私有权重（进镜像）
    └── <model-name>/
```

规则：

1. **被 ≥2 个算子使用**的模型只放 `shared/<model>/`，各算子通过 `configs/` 声明模型名，不复制权重。
2. **只有 1 个算子使用**的模型放 `weights/<operatorId>/<model>/`，不建 `shared/` 子目录。
3. 算子目录内不再建 `weight/`；`core.py` 通过 `WEIGHTS_DIR`/`configs` 解析实际路径。解析顺序：`WEIGHTS_DIR` > 本机/构建机模型仓（Windows `D:\models`、Linux `/models`，需含 `shared/`）> 仓库内 `operator/weights/`。
4. 权重文件不进 git；`SHA256SUMS` 进 git，`Dockerfile` 构建期校验。
5. 许可证未确认的模型不得放入本目录，登记到 `docs/算子开发/许可证清单.md` 待审批（Q-07）。
6. S0 阶段无权重，`healthz` 对 `requiresWeights=true` 的算子返回 `weightsOk=false`，但 `ready` 不受权重影响。S0 只做「`shared/` 或 `<operatorId>/` 是否有文件」的存在性检查；S1 起在 `configs/` 声明模型名后，可细化为按模型目录逐项检查。
7. **项目目录不放权重**：本机模型仓为 `D:\models`（Linux 服务器 `/models`），目录结构与 `operator/weights/` 对齐（`shared/<model>/`、`<operatorId>/<model>/`）。构建镜像前把模型仓的 `shared/` 拷入 `operator/weights/`，构建完成后可清理；仓库内只保留 `SHA256SUMS` 与 `.gitkeep`。
