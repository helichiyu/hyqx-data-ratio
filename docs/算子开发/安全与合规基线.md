# 数据配比中心 · 安全与合规基线（S0-7）

> 版本：`0.1.0`；日期：2026-11-16
> 适用范围：`operator/` 单镜像、22 个算子、样例数据、证据目录、构建与交付压缩包
> 依据：任务书 2.4 / 3.6 / 3.8、`docs/交接文档/02-环境部署与算子池配置.md`

## 1. 权重与模型

1. 权重文件**不进 git**：`operator/weights/*` 已由 `.gitignore` 排除，仅允许 `.gitkeep`、`SHA256SUMS`、说明文件。
2. 共享模型只存一份：≥2 个算子使用的模型放 `operator/weights/shared/<model>/`；单算子私有放 `operator/weights/<operatorId>/<model>/`。
3. `SHA256SUMS` 进 git；镜像构建期校验（`Dockerfile` 的 `sha256sum -c`）。
4. 许可证未确认的模型不得入镜像；登记到 `许可证清单.md`，走 Q-07 审批。
5. 权重不得包含个人数据、密钥、Token 或未脱敏语料。

## 2. 密钥与 Token

1. 仓库禁止提交 `.env`、`X-Token`、数据库/Redis 密码、对象存储 AK/SK；`.env` 与 `*.tar.gz` 已忽略。
2. 平台 `X-Token` 由部署环境注入（Secret/env），算子只做存在性校验与透传（`REQUIRE_X_TOKEN`，默认关闭），不实现账号体系。
3. 日志、证据、结果中不得出现 Token；`command.txt` 与 `environment.txt` 必须脱敏。
4. 交接文档中已进入 Git 历史的旧 Token 视为已泄露，上生产前必须轮换（交接文档 02 第 3 节）。

## 3. 语料与样例

1. 生产语料、原始批次、个人数据不进 git；大产物写 `OUTPUT_DIR` 或对象存储。
2. `docs/算子开发/samples/` 仅放可公开或已授权样例：
   - 维基百科文本：CC BY-SA，保留来源；
   - 《Noches blancas (1905)》扫描件：公有领域，保留 Wikimedia Commons 来源；
   - 内部项目素材（图像/音频/视频）：授权待确认（H-04），确认前仅限内网开发联调。
3. 样例必须登记来源、大小、SHA-256、授权状态（`samples/MANIFEST.json` + `SOURCES.md`）。
4. 样例不得用于效果验收；效果类指标无真值时写 `null` + `blockedReason`。

## 4. 个人信息与敏感数据

1. 样例中如出现人脸、证件、联系方式等 PII，必须替换或脱敏后才能入仓。
2. 数据敏感度/价值等级/业务关联度只能人工打标（分类体系「分级管控」要求），算子不得自动判定并入库。
3. PII 检测（OP-07/LBL-09）只输出建议与命中证据，是否处置由平台决定。

## 5. 依赖与供应链

1. `requirements.txt` 全部锁定版本；禁止运行期联网下载。
2. 基础镜像 `python:3.12-slim-bookworm`；系统包仅 `ffmpeg`、`libmagic1`。
3. 新增依赖必须：记录许可证 → 评估漏洞 → 更新 `许可证清单.md` → 人工确认。
4. 不使用来源不明的模型权重、二进制包或脚本。

## 6. 容器与运行期

1. 镜像以非 root 用户（uid/gid 10001）运行；`EXPOSE 17025`。
2. `INPUT_DIR`/`OUTPUT_DIR` 通过 volume 挂载，宿主机路径由部署环境注入。
3. 路径闸门、zip-slip、符号链接、大小限制由 `inference.py` 统一实现（见 `算子工程契约.md` 第 6/7 节）。
4. 长期任务必须幂等重跑、断点续跑；不得用 `sleep` 模拟进度。
5. 日志不打印语料正文、Token、绝对个人信息路径。

## 7. 交付物

1. 单镜像 `op-data-mixing:<version>`；单压缩包 `op-data-mixing-<version>.tar.gz`。
2. 压缩包只含 Docker 必要文件；`tests/dataset/output/docs/*.md`、密钥、生产语料一律排除。
3. 交付前核对：`bash scripts/package_docker_bundle.sh --version <version>` 的清单断言全部通过。

## 8. 自检命令

```bash
# 1) 仓库不应有权重文件（除 .gitkeep/SHA256SUMS/说明）
find operator/weights -type f ! -name '.gitkeep' ! -name 'SHA256SUMS'

# 2) 不应有 .env / Token / 私钥
git grep -nE '(X-Token|SECRET|PASSWORD|BEGIN (RSA|OPENSSH|PRIVATE) KEY)' -- ':!docs/交接文档/*' || true
git status --short

# 3) 压缩包清单
bash scripts/package_docker_bundle.sh --version 0.1.0
tar -tzf dist/op-data-mixing-0.1.0.tar.gz | grep -E '/(tests|dataset|output)/|\.md$|\.pyc$|__pycache__' && echo "异常" || echo "清单干净"

# 4) 样例来源与授权
python scripts/gen_sample_manifest.py
```
