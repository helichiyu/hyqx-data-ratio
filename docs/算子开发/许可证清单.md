## 6. 审批与登记规则

1. 新模型/权重入库前：登记许可证、来源 URL、SHA-256、商用限制 → 人工审批（Q-07）→ 放入 `operator/weights/`。
2. 许可证不明或冲突：登记 `BLOCKED`，不得静默使用。
3. AGPL/GPL 模型（如 YOLOv8、Neo4j 社区版）需评估分发方式，必要时替换为宽松许可证替代品。
4. 变更后同步更新本清单与 `安全与合规基线.md`。
