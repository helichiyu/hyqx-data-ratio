# DM 平台侧问题清单（内部待补，勿混入算法问题）

> 记录日期：2026-11-19
> 说明：打标缺权重、语音依赖、OP-06/OP-08 等属于算法侧，见 `算法侧问题清单-DM.md`。
> 本文件只记录**平台编排/功能未完成**的项，不要发给算法同事。

---

## 1. 七维仿真未接执行链（P0）

**现象**：配方包版本点「仿真 → 发起仿真」后任务 failed，提示：

```text
算子池已接入，但七维仿真依赖配比方案/画像产物，当前版本尚未编排该执行链，暂不能执行
```

**原因**：`SimulationServiceImpl.run()` 目前只做算法健康检查，随后直接抛 `NOT_READY`；
没有构造 OP-16（`dm-ratio-analysis`）所需的输入：

- OP-15 的 `plan.json`（配比方案 + 库存）；
- OP-05 标签、OP-08/OP-14 画像 metrics；
- 目标能力/来源权重等参数。

**归属**：平台侧编排，不是算法缺陷。算法侧 OP-16 已实现。

**待做**：
1. 从配方包版本快照解析 plan/scene；
2. 校验上游产物是否存在（OP-05/OP-15/OP-08/OP-14）；
3. 组装 OP-16 请求，落 `seven_dim_json` 与准入判定；
4. 上游缺失时给出具体缺哪一环，而不是统一 NOT_READY。

## 2. 配比生产未接执行链（P0）

**现象**：生产任务启动后 failed，提示：

```text
算子池已接入，但生产依赖已打标样本（OP-05）与配比方案（OP-15），当前版本尚未编排该执行链，暂不能执行
```

**原因**：`ProductionTaskServiceImpl.run()` 只创建任务/执行记录并做健康检查，没有：

- 从配方版本快照生成 OP-15 plan；
- 调用 OP-15 得到选样清单；
- 调用 OP-17（`dm-dataset-packaging`）打包成品 Parquet；
- 落阶段产物、逐算子运行、文件流转记录。

**归属**：平台侧编排（且依赖算法权重/标签数据）。不是算法缺陷。

**待做**：
1. 生产任务增加数据集来源（当前表没有数据集字段，需评估从配方方案/数据集快照取）；
2. 组装 OP-15 → OP-17 链路；
3. 产物写 `hs_data_mixing_stage_artifact` / `operator_run` / `file_transfer`；
4. 断点续跑与失败阶段回填。

## 3. 配比分析未接执行链（P0）

**现象**：分析任务启动后 failed；详情无结果，「生成报告」按钮禁用；PDF 明确提示暂不支持。

**原因**：`AnalysisServiceImpl.run()` 同样只做健康检查，未调用：

- OP-16（九维/配比分析）或 OP-19（`dm-ratio-reporting` 报告）；
- 未写 `hs_data_mixing_analysis_result`，所以没有结果可生成报告；
- PDF 报告本身未实现，只有 HTML/Excel。

**归属**：平台侧编排 + 平台功能缺失。算法侧 OP-16/OP-19 已实现。

**待做**：
1. 分析任务绑定生产任务/配方版本，收集上游 run 目录；
2. 组装 OP-19 `operator_results` bundle，写 analysis_result；
3. 报告生成读取结果 JSON；HTML/Excel 已实现，PDF 需另做；
4. 上游缺失时提示具体缺失项。

## 4. 版本差异仅统计新增/删除（P2）

**现象**：`changedCount` 始终为 0；节点改名表现为“删旧路径 + 加新路径”。

**原因**：`TaxonomyServiceImpl.versionDiff()` 只比较 `node_path` 集合，没有比较同一路径的属性变化。

**归属**：平台侧功能不完整。待补：按路径比较 nodeName/modal/status 等，填充 changedPaths。

---

## 5. 版本删除/清理缺失（P2）

**现象**：性能验证创建了多个「性能验证-批量快照」草稿版本，无法在页面删除。

**原因**：分类版本只有新建/生效，没有删除/归档接口。

**归属**：平台侧功能缺失。待补：仅允许删除非生效、未被业务引用的版本。

---

## 6. 为什么看起来“功能缺陷很多”

- 数据配比是完整链路：打标 → 配比方案 → 配方包 → 生产 → 分析 → 仿真/报告；
- 平台已完成 12 域接口、11 页 UI、任务生命周期、权限和**打标/画像真实算法链路**；
- 生产/分析/仿真三页目前只完成“任务生命周期 + 明确失败”，没有编排上游算子；原型里它们是完整可点的，所以对比起来像缺很多；
- 算法侧还缺 bge 权重，导致打标无法产样本，生产/分析即使编排也会卡在上游；
- 这些不是几十个独立 bug，而是**三页共用的执行编排层未完成 + 算法权重未交付**。

**建议顺序**：
1. 算法侧交付 bge 权重，打标跑通；
2. 平台补 OP-15 → OP-17 生产链路；
3. 平台补 OP-16/OP-19 分析与报告；
4. 平台补仿真 OP-16；
5. 版本差异/删除等 P2 收尾。
